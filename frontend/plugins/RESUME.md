# RESUME — Plugins de build (`/app/frontend/plugins`)

Plugins personalizados invocados por CRACO / webpack durante la compilación.

## Carpetas

| Carpeta | Descripción |
|---|---|
| `health-check/` | Plugin que añade un endpoint de diagnóstico al dev server para verificar que el frontend está compilando y sirviendo correctamente. Se usa desde la infraestructura de preview de Emergent. |
